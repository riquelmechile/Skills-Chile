# Seguridad

## No publiques secretos

Nunca agregues a una skill:

- API keys;
- tokens;
- contraseñas;
- cookies de sesión;
- claves privadas;
- `.env` reales;
- datos personales reales innecesarios.

## Ejemplos y datos

Usa datos ficticios, anonimizados o minimizados. En skills jurídicas, de salud, financieras o de seguridad, trata ejemplos reales como material sensible.

## Reporte de vulnerabilidades

No abras un issue público si el problema expone credenciales, datos personales o una vulnerabilidad explotable. Contacta al mantenedor por un canal privado de GitHub cuando esté habilitado.
